BMC AMI Backup and Recovery for IMS simplifies and automates the protection and recovery of IMS full-function databases, including High Availability Large Databases (HALDBs) and Fast Path data entry databases (DEDBs). It ensures data integrity, helps meet compliance requirements, and reduces downtime caused by data loss or system failures.

Managing IMS database backups require precision and reliability. BMC AMI Backup and Recovery for IMS offers a specialized approach that reduces manual effort and enhances operational efficiency.

With this solution, you can perform the following tasks:

Automate and streamline IMS database backup and recovery workflows.
Enables precise, point-in-time recovery of IMS RECON data sets by capturing and replaying all RECON updates.
Minimize downtime and reduce operational overhead.
Ensure recoverability with precise point-in-time and full-system recovery options.
Strengthen compliance and audit readiness with robust data protection features.

## Key product components and capabilities

The following table summarizes the components available in the BMC AMI Backup and Recovery for IMS product:

Component	Capabilities
Image Copy utility	
Produces various types of backups, including batch image copies, online (fuzzy) image copies, incremental image copies, copies of image copies, Snapshot copies, and Instant Snapshot copies.

For more information, see Getting started with Image Copy utility.

Change Accumulation utility	
Performs change accumulation of IMS log records for database changes and can also produce incremental image copies.

For more information, see Getting started with Change Accumulation utility.

Recovery utility	
It performs full recoveries, roll-forward recoveries, and point-in-time (PIT) recoveries of IMS databases.

The RECON Recovery Facility enables precise point-in-time recovery of IMS RECON data by logging every insert, update, and delete to support both backout and forward recovery without losing recent changes.

For more information, see Getting started with Recovery utility.

RECOVERY MANAGER	Simplifies and automates recovery-related operations:
Create, validate, and rebuild groups of databases
Check recovery assets
Create and manage recovery points
Synchronize log switches
Locate recovery points
Analyze logs
Generate recovery JCL
For more information, see Getting started with Recovery Manager for IMS.
